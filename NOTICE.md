# Source and license notice

Morning Report started from the Wizard builder's hello-wizard reference template (GPL-3.0-only, see LICENSE) and was rewritten as a read-only report reader. Its HTTP API and MCP share one service layer, and the view is vanilla JavaScript. The bundled `wizard-ui.css`, `boot.js` and `theme-client.js` are the template's unmodified appearance client (provenance in appearance-provenance.json). Python and the base image keep their upstream licenses. This repository contains no report content or personal configuration.
